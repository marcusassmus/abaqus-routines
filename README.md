# abaqus routines

This is a personal collection of routines for performing various computations in mechanics using the [ABAQUS FEA software](https://www.3ds.com/products/simulia/abaqus), with code written in FORTRAN and Python. They cover aspects of structural mechanics, mechanics of materials, and micromechanics.
